# Identity
Build a complete mobile-first Mongolian manhwa reading website called "Hello Manga Team".

IMPORTANT:
- The website must be designed primarily for Android/iPhone.
- Do not make it desktop-first.
- Use a dark black + navy blue theme.
- Make it modern, cute, clean and professional.
- All visible text must be in Mongolian.
- Make everything actually work, not just a visual mockup.
- Use sample manga data so the website is immediately usable.

HOME PAGE:
Create a header with:
- "Hello Manga Team" logo/title
- Search button
- Three-dot menu button

Three-dot menu must open a popup containing:
- Профайл
- Тохиргоо
- Dark Mode
- Admin

Home page sections:
1. "Топ Манхва"
2. "Шинэ гарсан ➡️"
3. "Сүүлд орсон ➡️"
4. "Санал болгох ➡️"
5. "Бүгд ➡️"
6. "Үргэлжлүүлэн унших"

Manga cards:
- Cover image
- Manga title
- Short description
- Views
- Translator name
- Heart/favorite button
- Free label
- Chapter information
- "Унших" button

Cards must be horizontal swipe/carousel on mobile, NOT a long vertical list.

MANGA DETAILS PAGE:
When a manga card is clicked, open its details page.

Show:
- Large cover
- Title
- Description
- Translator
- Views
- Favorite button
- "Үргэлжлүүлэн унших"
- Chapter list

Chapter list:
- Бүлэг 1
- Бүлэг 2
- Бүлэг 3
- etc.

Each chapter must be clickable.

READER PAGE:
Create a comfortable mobile manga reader.

- Show chapter images vertically
- Images should fit the phone screen
- No horizontal scrolling
- Previous chapter button
- Next chapter button
- Back to manga button
- Chapter title at the top
- Comments section at the bottom
- Save reading progress
- Remember the last chapter the user opened

PROFILE:
Create a profile page with:
- Profile picture
- Username
- Favorites
- Reading history
- Continue reading
- Saved manga

ADMIN:
Create an Admin page accessible from the three-dot menu.

Admin should allow:
- Add new manga
- Manga title
- Manga cover image upload from phone
- Description
- Translator name
- Category
- Add chapters
- Chapter title
- Upload multiple chapter images from phone
- Edit manga
- Delete manga
- Edit chapters
- Delete chapters

Make the Admin interface simple and easy to use on a phone.
